# Sudoku-Solving-Times-A-Statistical-Analysis
This project compares the performance of two Sudoku players on "Very hard" puzzles, using solving time as a proxy for skill and day of play as a proxy for experience. The analysis includes descriptive statistics, confidence intervals, a comparison of mean solving times, and regression models of each player's learning curve.

## Tools

- **IBM SPSS Statistics**
- **Microsoft Word** (report)
